# 环境
## oracle 环境配置
### linux+docker
#### 部署过程
```shell
docker volume create ora23-full-data
docker run -d --name ora23ai-full -p 1521:1521 -v ora23-full-data:/opt/oracle/oradata 10.130.159.213:5000/oracle-23ai-full:latest
docker exec ora23ai-full ./setPassword.sh <sys_password>
docker exec -it ora23ai-full sqlplus sys/<your_password>@FREE as sysdba
```
#### 部署结果
于10.130.159.236上部署五个docker，端口为1521-1525，密码为testdb
另有一个实验性docker，自用，端口1520，密码qwer
#### 报错

```sh
docker run -d --name ora23ai-full -p 1521:1521 -v ora23-full-data:/opt/oracle/oradata 10.130.159.213:5000/oracle-23ai-full:latest 

Unable to find image '10.130.159.213:5000/oracle-23ai-full:latest' locally docker: Error response from daemon: Get "https://10.130.159.213:5000/v2/": http: server gave HTTP response to HTTPS client 
```
Docker 默认要求使用 HTTPS 连接镜像仓库，而私有仓库 10.130.159.213:5000使用的是 HTTP 协议
1. 修改docker配置文件：
	```bash
	sudo vim /etc/docker/daemon.json
	```
2.  添加：
	```json
	{
    "insecure-registries": ["10.130.159.213:5000"]
	}
	```
3. 重启docker
	```bash
	sudo systemctl restart docker
	```
